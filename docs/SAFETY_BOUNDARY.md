# Safety Boundary

Angel Gates is an authorization layer. It is not a gate operator safety system.

## Standard Positioning

Angel Gates should be documented, marketed, sold, and installed as an authorization device equivalent to a keypad or reader controller.

It does not control, modify, certify, bypass, or monitor gate operator safety functions.

## Installation Boundary

Installation must be performed by a qualified gate access installer. The installer is responsible for confirming that the existing gate/barrier operator, entrapment protection devices, loops, photo eyes, reversing edges, signage, and site conditions remain compliant with applicable requirements.

## UL 294

The access-control layer should be designed with UL 294 expectations in mind because it regulates authorization, access decisions, activity reporting, and related control equipment.

## UL 325 And ASTM F2200

The gate or barrier operator side remains a separate safety domain. Angel Gates must not imply that it replaces UL 325 operator requirements, entrapment protection, or ASTM F2200 gate construction considerations.

## Relay Rule

The edge runtime may produce an authorized relay intent after a local allow decision. The field wiring must be designed so de-energized state means no intent is sent.

Power loss or Angel Gates failure should leave the existing gate system behaving as it did before installation.

## Contract Sentence

Angel Gates is an authorization device, equivalent to a keypad or access reader; it does not control, modify, or monitor gate operator safety functions, and installation must comply with UL 325 and ASTM F2200 by a qualified installer.
